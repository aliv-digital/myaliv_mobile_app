How to read a row	Each row is one Firebase Analytics event. The Code Samples tab gives the three additions per event — the event-name constant, any new parameter constants, and a typed method on AnalyticsService — plus the call site in the feature BLoC or Cubit. No feature code calls FirebaseAnalytics.logEvent directly. Rows marked Automatic need no code beyond SDK integration and screen tracking. Rows marked Reporting only are built in GA4/BigQuery from other events, not implemented in the app.
Type colour key	Green = GA4 standard/reserved event (use Google's name exactly — this is what unlocks GA4's built-in ecommerce and engagement reports).  Orange = custom ALIV event (name it exactly as written).  Blue = automatic / SDK-collected.  Grey = reporting-only or out of scope.  Yellow = open item, see Open Questions.
Naming rules	snake_case, max 40 chars, start with a letter. Never prefix with firebase_, google_ or ga_. Max 25 parameters per event, 25 user properties per project. Parameter values max 100 chars.
Privacy rule	No PII in any event or parameter — no names, emails, phone numbers, account numbers, card numbers or card details, no entered field values, no free-text failure messages. Failure reasons are sent as fixed non-sensitive categories. user_id must be a hashed or internal customer identifier.
